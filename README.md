# UtiloKit — 201 free, private, in-browser tools

Every tool at **[utilokit.com](https://utilokit.com)** runs 100% client-side: **no uploads, no accounts, no watermarks, no paywalls.** Once a page loads, most tools keep working offline. Available in 20+ languages.

**The privacy model:** your input is processed with browser APIs (canvas, `crypto.subtle`, in-page PDF handling). Nothing you type or upload is transmitted to a server — you can verify it yourself in DevTools' Network tab on any tool. Your PDF never leaves your machine when you sign it; your salary never leaves your machine when you calculate take-home pay.
